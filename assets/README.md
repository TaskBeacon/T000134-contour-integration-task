# Authored Gabor assets
200deterministic grayscale PNGs (100unique signal/null pairs), generated by scripts/generate_assets.py using NumPy and Pillow. Geometry, orientation, seed and SHA256 in manifest.json. No participant data or copyrighted paper figures. Same pixels used in native/web. Pixel geometry is uncalibrated; monitor metadata defaults are not measurements and do not enter the pixel rendering. No human pilot was performed. Generation includes rejection sampling of path crossings, duplicate cells, min18px spacing and null retained alignment. Some seeds require deterministic full-pair restart when background packing fails; final seed is retained.
